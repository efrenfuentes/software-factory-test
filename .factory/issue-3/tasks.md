- [x] T3 Implement `pub async fn log_requests(req: Request, next: Next) -> Response` in `src/logging.rs`. First add a private helper `read_body(Body) -> (Body, Option<Bytes>)`. It reads chunks through `into_data_stream()`; on a read error it returns `None` and a replay body (the chunks read so far, then the same error). The middleware runs the helper on the request and **always** calls `next`: there is no early 500. It then runs the helper on the response and rebuilds the response with the original parts, and emits one `tracing::info!` event with `method`, `uri` (path + query), `status`, `latency_ms`, `request_body` and `response_body` (via `format_body`, Debug-formatted). If a side failed to read, log `"<unreadable body>"` for it. Verify: `cargo build`.
